# olx_fetch

Находит объявления на olx.ua через публичный JSON API, которым пользуется сам
сайт, и превращает результат в удобный для чтения HTML-отчёт (открывается прямо
в браузере, в том числе в Mobile Safari на iOS — ссылку можно открыть или
сохранить на телефоне без установки приложения).

Общий клиент API — `olx_api.py` (постраничный обход категории или полнотекстовый
поиск + разбор объявления в единую структуру `Listing`), общее сохранение в
JSON/CSV — `olx_io.py`, общий рендер отчёта — `render_report.py`. Поверх них — два
готовых скрипта под конкретные запросы:

| Скрипт | Что ищет | Как фильтрует |
|---|---|---|
| `olx_fetch.py` | Аренда квартир на заданной улице в Киеве | Обходит всю категорию "довгострокова оренда" в Києві, локально проверяет вхождение названия вулиці |
| `olx_fetch_apple_silicon.py` | MacBook, Mac mini, iMac, Mac Studio, Mac Pro, iPad Pro на чипах Apple Silicon | Полнотекстовый пошук OLX по кожній лінійці пристроїв, залишає лише оголошення, де в назві/описі згадано M1–M5 |

## Использование

```bash
pip install requests

# Аренда на улице
python olx_fetch.py --street "франка" --output data/franko_kyiv_rentals.json
python render_report.py data/franko_kyiv_rentals.json report.html

# Apple-устройства на M1–M5
python olx_fetch_apple_silicon.py --output data/apple_m_series.json
python render_report.py data/apple_m_series.json apple_report.html
```

`render_report.py` понимает как плоский список объявлений, так и формат
`{"query": ..., "source_note": ..., "listings": [...]}` — во втором можно указать
заголовок отчёта и пояснение к данным (см. `data/*.json`). Наличие `query.street`
переключает оформление на "аренда" (иконка воріт, заголовок "Оренда на …"); без
него используется нейтральное оформление для любых других объявлений (иконка
чипа), с заголовком/подзаголовком из `query.title`/`query.subtitle`.

Оба скрипта используют новый список для каждого объявления — `Listing.tags`
— вместо жёстко заданных полей вроде "кімнати"/"поверх", поэтому один и тот же
рендер одинаково хорошо показывает и характеристики квартиры, и характеристики
техники.

## Ограничение сети

В некоторых песочницах (в т.ч. в среде, где готовился этот репозиторий) исходящий
доступ к `www.olx.ua` заблокирован политикой egress-прокси. `olx_fetch.py`
написан и готов к работе, но реальный прогон с постраничным обходом API нужно
делать в окружении, откуда `www.olx.ua` доступен. `data/franko_kyiv_rentals.json`
сейчас содержит небольшую выборку, найденную через веб-поиск (с реальными
ссылками на OLX), — как рабочий пример для `render_report.py`, а не полный
живой результат.
