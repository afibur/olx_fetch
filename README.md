# olx_fetch

Находит объявления о долгосрочной аренде квартир на заданной улице в Киеве через
публичный JSON API, которым пользуется сам сайт olx.ua, и превращает результат в
удобный для чтения HTML-отчёт (открывается прямо в браузере, в том числе в Mobile
Safari на iOS — ссылку можно открыть или сохранить на телефоне без установки
приложения).

## Использование

```bash
pip install requests

# 1. Получить объявления (пагинация по всей категории аренды в Киеве,
#    локальная фильтрация по подстроке в названии улицы)
python olx_fetch.py --street "франка" --output data/franko_kyiv_rentals.json

# 2. Собрать читаемый HTML-отчёт из полученных данных
python render_report.py data/franko_kyiv_rentals.json report.html
```

`render_report.py` понимает как результат `olx_fetch.py` (плоский список), так и
формат `{"query": ..., "source_note": ..., "listings": [...]}` — во втором можно
указать заголовок отчёта и пояснение к данным (см. `data/franko_kyiv_rentals.json`).

## Ограничение сети

В некоторых песочницах (в т.ч. в среде, где готовился этот репозиторий) исходящий
доступ к `www.olx.ua` заблокирован политикой egress-прокси. `olx_fetch.py`
написан и готов к работе, но реальный прогон с постраничным обходом API нужно
делать в окружении, откуда `www.olx.ua` доступен. `data/franko_kyiv_rentals.json`
сейчас содержит небольшую выборку, найденную через веб-поиск (с реальными
ссылками на OLX), — как рабочий пример для `render_report.py`, а не полный
живой результат.
