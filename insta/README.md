# Скачивание фото и видео из Instagram и TikTok на телефон

Скрипт `insta_dl.py` скачивает из Instagram посты, карусели (все фото/видео), reels и stories,
а из TikTok — видео и фото-посты (слайдшоу; музыка не сохраняется).
Внутри — [gallery-dl](https://github.com/mikf/gallery-dl), запасной вариант — [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## iPhone — кнопка «Поделиться» → сразу в Фото

### 1. Установка (один раз)

1. Установите бесплатное приложение **a-Shell** из App Store (не путать с «a-Shell mini»).
2. Откройте a-Shell и выполните по очереди:
   ```bash
   pip install gallery-dl yt-dlp
   curl -fL https://raw.githubusercontent.com/afibur/olx_fetch/main/insta/insta_dl.py -o ~/Documents/insta_dl.py
   mkdir -p ~/Documents/Instagram/new
   ```
3. Убедитесь, что скрипт на месте: `ls ~/Documents` — в списке должен быть `insta_dl.py`.
4. Проверка — скопируйте ссылку на любой пост и выполните:
   ```bash
   python ~/Documents/insta_dl.py https://www.instagram.com/p/XXXXXXX/
   ```
   Должно написать «Готово, сохранено файлов: N».

### 2. Быстрая команда (один раз)

Откройте приложение **Команды** → **+** (новая команда) и добавьте действия по порядку:

| # | Действие (поиск по названию) | Настройка |
|---|---|---|
| 1 | **Получить URL-адреса из ввода** | ввод: «Ввод быстрой команды» |
| 2 | **Execute Command** (a-Shell) | команда: `python ~/Documents/insta_dl.py ` + переменная **URL-адреса** + ` -o ~/Documents/Instagram/new` |
| 3 | **Получить содержимое папки** | папка: Файлы → На iPhone → **a-Shell → Instagram → new** |
| 4 | **Сохранить в фотоальбом** | нажмите «Недавние» и выберите свой альбом (сначала создайте его в Фото: Альбомы → + → Новый альбом) |
| 5 | **Удалить файлы** | ввод: «Содержимое папки», выключите «Подтверждать перед удалением» |
| 6 | **Показать уведомление** (необязательно) | текст: «Сохранено в Фото» |

Затем нажмите **ⓘ** внизу (или стрелку у названия) и:
- включите **«Показывать в меню „Поделиться“»**;
- типы данных — оставьте только **URL-адреса** и **Текст**;
- назовите команду, например **«Скачать из Insta»**.

При первом запуске iOS спросит разрешения (доступ к a-Shell, к папке, к Фото) — разрешите «Всегда».

### 3. Использование

Instagram → пост / reel → **Поделиться (самолётик) → Ещё (⋯) → «Скачать из Insta»**.
Если команды нет в списке — пролистайте вниз, «Изменить действия» и добавьте её в избранное.
Или: «Копировать ссылку» → запустить команду из виджета (тогда в шаге 1 вместо ввода используйте «Буфер обмена»).

**TikTok** — та же команда, ничего менять не нужно: видео или фото-пост → **Поделиться → Ещё (⋯)
/ «Другое»** → «Скачать из Insta». Файлы называются `tiktok_<id>…` и попадают в тот же альбом.
Видео TikTok без водяного знака бывает не всегда — зависит от того, что отдаёт сам TikTok.

### Если что-то не так

- **Команда завершилась, а в Фото пусто** — значит шаг 3 начался раньше, чем скачалось.
  В действии Execute Command откройте «Показать больше» и включите режим, при котором
  команда выполняется в окне a-Shell (не в фоне), и добавьте в конец команды ` ; open shortcuts://`
  — после скачивания a-Shell вернёт вас в Команды.
- **Ошибка в a-Shell** — откройте a-Shell и запустите команду из шага 1.3 вручную: будет видно сообщение.
- Файлы всегда можно найти вручную: **Файлы → На iPhone → a-Shell → Instagram**.

## Android (рекомендуется) — через кнопку «Поделиться»

1. Установите из **F-Droid** (не из Google Play — там устаревшие версии):
   - **Termux**
   - **Termux:API** (чтобы файлы сразу появлялись в Галерее)
2. Откройте Termux и выполните одну команду:
   ```bash
   curl -sL https://raw.githubusercontent.com/afibur/olx_fetch/main/insta/setup_termux.sh | bash
   ```
   Разрешите доступ к файлам, когда спросит.
3. Готово. В Instagram: пост/reel → **Поделиться → (Ещё) → Termux**.
   Файлы сохраняются в `Pictures/Instagram` и видны в Галерее.

Вручную из Termux тоже можно:
```bash
python ~/insta/insta_dl.py https://www.instagram.com/reel/XXXXXXX/
```

## Если пишет «login required» / приватный аккаунт / stories

Instagram часто требует вход. Экспортируйте cookies из браузера, где вы залогинены
(расширение «Get cookies.txt LOCALLY» на компьютере), и положите файл как
`~/Documents/cookies.txt` (iPhone — перекиньте через AirDrop в «Файлы → a-Shell») или `~/insta/cookies.txt` (Android).
Скрипт подхватит его автоматически. Никому не передавайте этот файл — это доступ к аккаунту.

## Обновление

Instagram регулярно что-то меняет; если перестало качать:
```bash
pip install --upgrade gallery-dl yt-dlp
```
(на iPhone — в a-Shell, на Android — в Termux). Новая версия самого скрипта на iPhone — повторите команду `curl` из шага 2.
